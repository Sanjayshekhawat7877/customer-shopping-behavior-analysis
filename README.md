# Customer Shopping Behavior Analysis

## Overview
This project focuses on analyzing customer shopping behavior to identify
purchasing patterns, customer preferences, and key business insights.

## Tools & Technologies
- Python (Pandas, NumPy)
- SQL
- Excel
- Power BI

## Key Analysis Performed
- Customer segmentation and purchasing behavior analysis
- Identification of repeat and high-value customers
- Analysis of product category performance
- Sales trend and revenue insights

## Dashboard
An interactive Power BI dashboard was created to visualize KPIs such as:
- Total Sales
- Average Order Value
- Purchase Frequency
- Product Category Performance

## Business Impact
The insights from this analysis can help businesses improve marketing strategies,
optimize inventory planning, and increase customer retention.
