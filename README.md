 🛒 Customer Shopping Behavior Analysis

## 📌 Project Overview
The objective of this project is to perform an end-to-end data analytics workflow and demonstrate the ability to convert raw customer data into meaningful business insights using Python, SQL, and Power BI.

- ✅ Data Preparation & Exploratory Data Analysis (Python): Cleaned and transformed raw datasets to prepare them for analysis.
- ✅ Data Analysis (SQL): Executed queries to analyze customer segments, loyalty patterns, and purchasing behavior.
- ✅ Visualization & Insights (Power BI): Developed an interactive dashboard to highlight key trends and KPIs for decision-making.
- ✅ Reporting: Summarized key findings and business insights to support data-driven decisions.


## 🛠️ Tools & Technologies
- 🐍 Python (Pandas, NumPy)
- 🗄️ SQL
- 📑 Excel
- 📊 Power BI

## 📈 Key Analysis Performed
- 👥 Customer segmentation and purchasing behavior analysis
- 🔁 Identification of repeat and high-value customers
- 🏷️ Analysis of product category performance
- 📉📈 Sales trends and revenue insights

## 📊 Dashboard
An interactive Power BI dashboard was created to visualize KPIs such as:
- 💰 Total Sales
- 🧾 Average Order Value
- 🔄 Purchase Frequency
- 🛍️ Product Category Performance

## 🚀 Business Impact
The insights from this analysis help businesses:
- 🎯 Improve marketing strategies
- 📦 Optimize inventory planning
- 🤝 Increase customer retention
